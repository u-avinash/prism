Distributed trace correlation is not available yet

Prism accepts OTLP traces at POST /v1/traces, but does not currently persist spans, correlate them to incidents, or present live trace data.

Current capability

Acknowledgement only

Incoming trace payloads are authenticated and validated at the ingestion boundary. Prism returns aggregate span statistics to confirm receipt, but the payload is not stored after the request completes.

Use the incident list and telemetry log viewer for currently persisted, project-scoped operational data.

Required before this page can show live data

  • Tenant-scoped trace and span persistence with retention controls
  • Trace, span, and incident correlation identifiers
  • Query APIs with filtering, pagination, and authorization checks
  • Latency and failure aggregation calculated from persisted spans
