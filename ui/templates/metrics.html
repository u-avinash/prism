Metric analysis is not available yet

Prism accepts OTLP metrics at POST /v1/metrics, but does not currently retain metric time series, calculate service metrics, or display live values.

Current capability

Acknowledgement only

Incoming metric payloads are authenticated and counted by metric type. The request response confirms receipt, but metrics are not written to a time-series store and cannot be exported from Prism.

For supported operational reporting, use incident analytics, the project-scoped telemetry log viewer, and workflow health.

Required before this page can show live data

  • Tenant-scoped metric time-series persistence and retention policies
  • Aggregation/query APIs for time windows, dimensions, and pagination
  • Incident correlation and reliable service-level objective calculations
  • Export generated from persisted metrics, not browser-side sample values
