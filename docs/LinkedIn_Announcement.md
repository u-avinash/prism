# LinkedIn Announcement

I'm excited to share **Prism**, an AI-powered incident-management platform built to reduce the gap between a production error and a safe, reviewable remediation.

Prism ingests OpenTelemetry logs, detects and prioritizes incidents, generates an AI-assisted Root Cause Analysis and proposed fix, produces a PDF report and a unified patch, and then pauses for **human approval** before creating downstream artifacts -- Jira issues and GitHub pull requests.

What I value most about the design is the governance model: automation assembles evidence and accelerates coordination, while people retain the release decision. Project scoping, encrypted integration configuration, audit records, durable workflow history, and controlled recovery are first-class concerns.

The platform brings together Python, FastAPI, LangGraph/LangChain, OpenTelemetry, SQLite/SQLAlchemy, Jinja2/SSE, and configurable integrations for LLM providers, GitHub, Jira, Slack/Teams, and MuleSoft Anypoint.
