🚨 What if production incidents arrived with a governed, reviewable remediation package instead of only a raw alert?

I built Prism—an open-source AI-assisted incident-management platform that turns qualifying OTLP error logs into a structured engineering workflow.

The flow:

1️⃣ An application or OpenTelemetry Collector sends an OTLP error log  
2️⃣ Prism persists telemetry, resolves the project, and deduplicates repeated errors with SimHash  
3️⃣ It assesses severity and, for qualifying incidents, runs a LangGraph workflow  
4️⃣ The workflow prepares:
   → AI-assisted Root Cause Analysis with available code/runtime context  
   → Proposed code fix and test suggestion  
   → Quality reflection: correctness, safety, code quality, completeness  
   → Downloadable patch and RCA PDF  
5️⃣ ⏸️ It pauses for a human reviewer  
6️⃣ Only after approval, configured notifications, Jira creation, and GitHub PR creation can proceed

The key principle is intentional:

🔒 **AI prepares; humans decide; the system executes approved work.**

No code is deployed to production by Prism. Reviewers can inspect the evidence package, comment, reject, or request regenerated fixes with feedback before any Jira or GitHub delivery action.

Recent platform work also strengthened the operational boundary:

• Production ingestion requires a project API key  
• The production configuration is fail closed for auth, tenant assignment, CORS, secure cookies, and CSRF  
• Project integrations are encrypted at rest  
• Workflow-run and node-event history provide operational evidence without retaining prompts, source code, or generated fixes in those records  
• Admins can perform an audited recovery of incomplete approved post-approval work—without repeating the RCA, fix, or approval decision  
• Trace and metric intake is currently acknowledged but not persisted; this boundary is stated explicitly in the UI and docs

Prism is built with Python, FastAPI, LangGraph, SQLite/SQLAlchemy, OpenTelemetry, and pluggable LLM providers.

The repository includes a credential-free local Postman regression suite. For production, deploy behind trusted TLS infrastructure and route OTLP through a collector or gateway that injects a per-project ingestion key.
